## 📝 Project Description

The **Contact Management System** is a C program that allows users to manage their contacts effectively. It provides functionalities to add, search, update, delete, and display contacts. The contacts are stored in a **linked list** data structure, and the program offers a **text-based menu** to choose different actions.

---

## 📋 Features

### 🔹 Add New Contact:
- Add a contact with **name**, **phone number**, and **email**.
- Ensure proper validation of user input (e.g., valid phone number format, no empty fields).

### 🔹 Search Contact:
- Search for a contact by either **name** or **phone number**.
- Display the contact’s **details** (name, phone number, email) if found.
- Provide feedback if the contact is **not found**.

### 🔹 Update Contact:
- Update the **phone number** or **email** of an existing contact.
- Search by name or phone number to locate the contact.
- Provide feedback if the contact is **not found**.

### 🔹 Delete Contact:
- Delete a contact from the contact list.
- Search by name or phone number to locate the contact and remove it from the list.
- Provide feedback if the contact is **deleted** or **not found**.

### 🔹 Display All Contacts:
- Display the list of all contacts stored in the **linked list**.
- Show contact details in a clear format.

---

## 🛠️ Data Structure

The program uses a **linked list** to store contact details, where:
- Each **node** in the list represents a **contact**.
- Each node contains the contact's **name**, **phone number**, and **email**.

---

## ⚙️ Functional Requirements

1. **Linked List Implementation**: 
   - The contact list is implemented using a **linked list** where each node holds contact information.
   
2. **Text-based Menu**:
   - The program provides a simple **text-based menu** for users to select actions like adding, searching, updating, deleting, and displaying contacts.
   
3. **Input Validation**:
   - Ensure that the user inputs are properly validated (e.g., valid phone number, no empty fields, valid email format).

4. **Contact Limit**:
   - The program can store up to **100 contacts**. Provide feedback if the contact list is full.

5. **Error Handling**:
   - The program handles errors gracefully, providing appropriate feedback after each action, such as:
     - "Contact added successfully"
     - "Contact not found"
     - "Contact updated successfully"
     - "Contact deleted successfully"
